기존 운영 need-step50는 같은 dev 근거에서 review7·skip5·unknown4로 구분했습니다. 새 합성 기대와 일치한 것은15/16건이며, 단순 표시 동작 변경 한 건을 skip으로 판정했습니다. 기존 router-v1은 medium8·unknown4·Astra4를 냈고 Astra4는 Sol-only 후보에서 안전하게 거절됐습니다. 기존 질문과 선택지가 v2와 달라 엄밀한 동일 문항 정확도 비교는 아닙니다. 이 결과는 기존 모델이 모든 입력에 무조건 review/high만 내는 것은 아니라는 근거입니다.

재개 코드가 MPS optimizer 이동 후 CPU checkpoint 참조를 유지하는 것은 확인해 해제했습니다. 해당 파일 크기는270,613,461 bytes이며, 이 사본만으로 시스템 swap7.23GB 증가를 설명할 수 없습니다. 추가 tensor 적재 진단은 자동 승인 검토가 메모리 압박 위험으로 거절했습니다. 안전한 파일 크기 조회로 보완했고 추가 학습은 하지 않았습니다. 이 수정이 메모리 문제를 해결했다는 증거는 없습니다.
