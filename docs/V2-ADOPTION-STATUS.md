# v2 소스 병합 / 운영 비활성

2026-10-18 사용자 결정: #3의 공동 판정 코드와 #4의 학습 증거·메모리 검증 보완을 병합합니다. 이번 승인은 **소스 통합**이며 재학습·실제 모델 평가·가중치 배포·운영 활성화 승인이 아닙니다.

- 기존 `judge`/`doctor`와 v1 런타임·가중치·평가 기록을 유지합니다.
- 새 모델의 운영 pin `provenance/discrimination-weights.json`을 만들지 않고 가중치를 내려받거나 배포하지 않습니다. pin이 없으면 v2는 모델 로드 전에 중단됩니다.
- Baby-steps의 `routing.discrimination_enabled`를 새로 켜지 않습니다. 기존 runtime.json·에이전트 설정·설치된 스킬을 변경하지 않습니다.
- 새 학습, step50 재개, dev 후보 선택, Kev/Jev final 평가, 기존 final 재사용/재실행을 수행하지 않습니다. 기존 중단 기록은 보존합니다.
- `skip`은 참고 추천이며 자동 리뷰 생략을 허용하지 않습니다. 소스 병합은 실무 품질 향상이나 토큰 절감의 증거가 아닙니다.

기존 환경에 이미 v2 플래그나 실험용 가중치가 있다면 이 문서만으로 해당 환경이 비활성이라고 판단하지 않습니다. 코드 갱신 전에 실제 설정과 pin의 출처를 읽기 전용으로 확인하고, 변경은 별도 승인 범위로 둡니다. `discriminate`를 명시적으로 실행하거나 평가 전용 manifest를 전달하는 동작도 이번 설치 절차에는 포함하지 않습니다.

## 나중에 활성화를 검토할 때

현재 동결된 실험은 step25까지만 완료됐고 step50은 안전 중단됐습니다. 사용자 요청과 적합한 Mac/MPS 환경을 확보한 뒤, 기존 protocol과 데이터·가중치·학습 증거의 해시 및 final 1회 제한을 보존하며 남은 절차를 계획합니다. CUDA 이식이나 평가 기준 변경은 별도 작업입니다. 메모리 제한을 낮추거나 성공 기록을 만들어 이번 보류를 우회하지 않습니다.

검증용 2×1 CPU 모델의 optimizer/RNG 회귀 검사는 실제 Kev 재학습·MPS 검증과 구분합니다. 자세한 기존 실험 상태는 `discrimination/results/summary.json`, `docs/2026-10-17-memory-admission.json`에 남아 있습니다.
